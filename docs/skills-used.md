# Skills used

The Matt Pocock engineering skills (in `.claude/skills/`) used to build this project, in workflow order.

| # | Skill | Used for |
| --- | --- | --- |
| 1 | `setup-matt-pocock-skills` | Configure the repo: issue tracker, triage labels, domain docs (`docs/agents/`). |
| 2 | `grilling` | Stress-test the plan for the assessment before anything was written. |
| 3 | `domain-modeling` | Build the domain language in `GLOSSARY.md`. |
| 4 | `to-spec` | Turn the grilling into spec #1 and agree the test seams. |
| 5 | `to-tickets` | Split the spec into tickets #2–#7 and publish them as GitHub issues. |
| 6 | `implement` | Work each ticket. |
| 7 | `tdd` | Red → green tests at the agreed seams, within each ticket. |
| 8 | `code-review` | Review each ticket on two axes: standards and spec. |
| 9 | `pr` | Write the description for PR #8. |
